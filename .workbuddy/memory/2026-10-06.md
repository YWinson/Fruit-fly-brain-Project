## 文献精读 + 开源先例调研（同日追加）

用 pypdf 逐篇抽取正文（非只读摘要）后确认的关键事实：

- **flyvis (Lappalainen 2024)**：用真实连接组约束 64 个细胞类型建模视叶运动通路，神经元/突触参数靠深度学习优化；50 个模型预测与 26 项活体实验吻合。**关键：明确论证"稀疏连接 → 单神经元预测更准"**（引 MNIST 稀疏度实验）；做了 ablation：random DMN（随机单细胞参数 + 完整连接组约束）等。开源 `github.com/TuragaLab/flyvis`。
- **FlyWire (Dorkenwald 2024)**：139,255 神经元 / 5×10⁷ 突触，成年雌蝇；118,501 为脑内固有神经元；提供 projectome（脑区间投射图）。**论文自己指出大神经元应按 subcellular compartment 而非整细胞作为连接组节点**——这条对 M2 的"节点粒度"设计直接相关。
- **BNCI2014-001 数据规格**（MOABB 论文 Table 1 实测）：9 被试 / 22 通道 / 250 Hz / 2 session × 6 run / 每类每 session 72 trial / 4 类（RH, LH, F, T），共 576 trial。
- **MOABB 跨被试基准数字**（论文附录表 D 系列，被试内 RH vs LH，BNCI2014-001 列为最强）：ACM+TS+SVM 91.71±10.30、CSP+LDA 82.34±17.26、CSP+SVM 83.07±16.53、DeepConvNet 82.07±15.52、EEGNet-8,2 77.15±19.33。→ **M1 的基线数字直接对标这里，不要自己拍。**
- **EEGNet (Lawhern 2018)**：depthwise + separable 卷积；**dropout 跨被试= 0.25（被试内 = 0.5）**——这个数对"等效 dropout 对照臂"的稀疏度设定有直接参考价值。

### 开源先例结论（对导师例会很关键）

- **⚠️ 最强邻近先例**：arXiv:2509.14447Nallani et al.，"Biologically Plausible Online Hebbian Meta-Learning: Two-Timescale Local Rules for Spiking Neural Brain Interfaces"—— 已把**三因子 + 双时间尺度资格迹**用于 **BCI 信号解码**（猕猴数据、闭环）。即 M4 的"三因子机制 × 神经解码"叙事**已有占位者**，我们的差异必须落在"规则来自可查证的果蝇接线图 + 进入运动想象 EEG 跨被试场景"。
- **人脑连接组先验用于解码已有工作**：Nature Biomedical Engineering 2025 `py_neuromodulation`（DBS/连接组知情解码器 + CEBRA，开源）；RGNN/arXiv:1907.07835（用符合生物原理的稀疏邻接矩阵 + 跨被试 NodeDAT，正则化 EEG 情绪识别，有开源）；DeeperBrain（浙大潘纲，物理先验嵌入架构的EEG 基础模型）。
- **"生物接线 → 网络拓扑先验"这条路线方法论上已被反复验证**：Surrey TSM/ETSM（Neurocomputing 2025, 10.1016/j.neucom.2025.131740，拓扑稀疏化 + 剪枝，99% 稀疏仍保精度）；MICrONS 连接组约束 RNN（CNS*2025 P064，用真实突触连接 + 神经元距离做权重初始化 + 距离正则，modularity/small-worldness 同时升高）；Cannistraci-Hebb training（arXiv:2501.19107，1% 连接超全连接）。→ **我们的新颖性不在"用生物接线约束网络"本身，而在于果蝇全脑连接组 + 运动想象 EEG 跨被试 LOSO 这条具体路径。**
- **flyvis 官方开源** `github.com/TuragaLab/flyvis`（模型权重 + 稀疏度实验代码）；flybody 亦开源。

### 需要在设计草案里正面回应的风险

1. M4 的"三因子×解码"叙事撞Nallani 2509.14447 → 必须明确划界。
2. M2 的稀疏度阈值不能自己拍 → flyvis 给了"稀疏连接才预测得准"的定量论证，但其 MNIST 稀疏度扫描不能直接搬到 EEG；需靠导师的 δ 阈值（SESOI）+ 等效 dropout 对照来兜底。
